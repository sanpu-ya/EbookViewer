# 操作と画面

EbookViewer の操作とキー割り当て、表示の設定です。
本文の組み方や形式ごとの読み込みのしくみは [実装のしくみ](implementation.md) にあります。

## 本文の操作

| 操作 | Mac | iPhone / iPad |
|---|---|---|
| ファイルを開く | ⌘O、ウィンドウへドロップ、Finder で開く | ツールバー「開く」、Files アプリから共有 |
| 目次 | ⌘T (本文フォーカス時は `t`)、Esc で閉じる | ツールバー「目次」(iPhone はシート、iPad はサイドバー) |
| 次のページ | ← (縦書き) / → (横書き)、PageDown、Space、↓、ホイール、画面左端クリック、⌘] | 画面左端タップ (縦書き)、スワイプ |
| 前のページ | → (縦書き) / ← (横書き)、PageUp、Shift+Space、↑、画面右端クリック、⌘[ | 画面右端タップ (縦書き)、スワイプ |
| 章の先頭／末尾 | Home / End | — |
| リンクを戻る／進む | ⌘⌥[ / ⌘⌥]、ツールバーの ↩ ↪ | ツールバーの ↩ |
| 文字サイズ | ⌘+ / ⌘- | 「表示」メニュー |
| 組方向 | ツールバー / ⌘⇧W (自動 → 縦書き → 横書き) | ツールバー |
| 本文エンジン | 「表示」メニュー / ⌘⇧E (stone_engine ⇄ WebView) | ツールバー「表示」 |

| ツールバーを隠す | — | 画面中央をタップ |

## 組方向と本文エンジン

本文を組む「本文エンジン」は stone_engine (既定) と WebView の 2 つで、「表示」メニューから切り替えます (⌘⇧E)。
組方向は「自動 → 縦書き → 横書き」の順に切り替えられます (⌘⇧W)。「自動」では書籍側の宣言を優先し、
宣言が無ければ日本語の本を縦書きにします。エンジンごとの組版の違いは
[実装のしくみ](implementation.md#縦書き表示のしくみ) にまとめてあります。

## フォント

本文の既定フォントは Hiragino Mincho ProN (明朝) / Hiragino Sans (ゴシック) です。指定した書体に
その文字が無いときは、ほかの文字種の書体を試し、それでも無ければシステムに探してもらいます
(♡ や ♪ のような記号が豆腐にならないように)。
異体字セレクタ (U+E0100 など) は場所を取らず、何も描きません (字形の切り替えには未対応です)。

## コミックの操作

右開き (マンガ) / 左開きの切替、単ページ・見開き (横長の画面では自動で見開き、横長ページと表紙は単独表示)・
縦スクロール (Webtoon)、ページ全体 / 幅 / 高さへのフィット、ピンチ・⌘+ ⌘- による拡大、色の反転・グレースケール・背景色、
サイドバーのサムネイル一覧、ページスライダー、読書位置の記憶に対応します。

| 操作 | Mac | iPhone / iPad |
|---|---|---|
| 次 / 前のページ | ← → (読み方向に従う)、PageDown / PageUp、Space / Shift+Space、↓ / ↑、ホイール、画面端クリック、⌘] / ⌘[ | 画面端タップ、スワイプ |
| 最初 / 最後のページ | Home / End | ページスライダー、ページ一覧 |
| 読み方向 | ツールバー、`d`、⌘⇧D | ツールバー「コミック」 |
| ページ配置 (単ページ / 見開き / 縦スクロール) | ツールバー、「コミック」メニュー | ツールバー「コミック」 |
| 見開きを 1 ページずらす (1 ページ進む / 戻る) | ツールバー (見開き時)、Shift+← →、⌘⇧] / ⌘⇧[ | ツールバー「コミック」→「ページ配置」 |
| 拡大 | ⌘+ / ⌘- / ⌘0、ピンチ、ダブルクリック | ピンチ、ダブルタップ |
| 色の反転 / グレースケール / 背景 | ツールバー「画像」、⌘⇧I | ツールバー「コミック」 |
| ページ一覧 | ⌘T / `t` (サイドバー) | ツールバー「ページ一覧」 |

## 設定と読書位置の保存

読書位置 (章とページ位置) と設定は `~/Library/Application Support/EbookViewer/` の `positions.json` `settings.json` に保存され
(サンドボックス内では `~/Library/Containers/com.sanpu-ya.EbookViewer/Data/Library/Application Support/EbookViewer/`)、
次回同じファイルを開くと復元されます。「最近開いたファイル」はセキュリティスコープ付きブックマークで保持するので、サンドボックス内でも再度開けます。

## ライセンス表示

同梱しているソフトウェアのライセンス原文をアプリ内で読めます。macOS はアプリメニューの「EbookViewer について」の下の「ライセンス…」、
iOS / iPadOS はツールバーの「表示」(コミックでは「コミック」) メニューの末尾にあるバージョン表示の下の「ライセンス…」から開きます。
一覧から選ぶと原文が等幅で表示され、選択してコピーできます。

原文は [`App/EbookViewer/Licenses/`](../EbookViewer.Apple/App/EbookViewer/Licenses/) の `.txt` をそのままバンドルに入れたもので、
EbookViewer 本体 (MIT)、stone_engine (MIT)、Unrar.swift (MIT)、unrar (UnRAR ライセンス) の 4 件です。
unrar は配布物にライセンス全文を含めることが条件なので、この画面がその条件を満たします。
ライセンスを足したり差し替えたりしたときは、`.txt` を置いて [`LicensesView.swift`](../EbookViewer.Apple/App/EbookViewer/LicensesView.swift) の `LicenseEntry.all` に 1 行足します。
